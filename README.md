# learn-python-data-analysis-with-phoebe

Decode the data job market, learn real analysis. Eight 45-minute sessions that take one messy real dataset - 124,000 LinkedIn job postings - all the way from raw download to a shareable report. NumPy, pandas, matplotlib, seaborn, and a first machine-learning model, taught as the workflow analysts actually use.

The hands-on sequel to [learn-python-with-phoebe](https://phoebefu6.github.io/learn-python-with-phoebe/).

**Live site:** https://phoebefu6.github.io/learn-python-data-analysis-with-phoebe/

## The running project

One dataset, carried across every session: the [LinkedIn Job Postings (2023-2024)](https://www.kaggle.com/datasets/arshkon/linkedin-job-postings) dataset on Kaggle. It is genuinely messy - about 70% of postings have no salary, pay is split across columns, titles are free text, and there are duplicates. That mess is the curriculum. By Session 8 you ship a report: five charts, five findings, and a simple salary model.

## The sessions

| # | Session | You learn |
|---|---------|-----------|
| 1 | Set up, and meet the mission | The stack, the analysis workflow, load + profile the data |
| 2 | NumPy foundations | Arrays, vectorization, broadcasting, boolean masks |
| 3 | pandas core | Series/DataFrame, loc vs iloc, filtering, summaries |
| 4 | Cleaning messy data | missingno, missing values, dtypes, text, duplicates |
| 5 | Explore and aggregate | groupby, pivot tables, merging the tables |
| 6 | Matplotlib fundamentals | Figure/Axes, the four core charts, labels, saving |
| 7 | Seaborn and the polish | Statistical charts, correlation heatmaps, themes |
| 8 | From insight to a shareable report | Findings, a salary model, packaging and shipping |

## Sources taught

The working content of the official [pandas](https://pandas.pydata.org/docs/), [NumPy](https://numpy.org/doc/stable/), [matplotlib](https://matplotlib.org/stable/), and [seaborn](https://seaborn.pydata.org/) docs, the free [Kaggle micro-courses](https://www.kaggle.com/learn) (Pandas, Data Visualization, Intro to ML), and Wes McKinney's open-access [Python for Data Analysis, 3e](https://wesmckinney.com/book/). Certificates, graded exercises, and videos stay on those platforms - links are provided throughout.

Static HTML/CSS/JS, no build step. Just open `index.html`.
